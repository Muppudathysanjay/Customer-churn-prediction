# Customer Churn Prediction: Data Cleaning & Visualization

## Objective
Analyze customer churn data by cleaning, preprocessing, and visualizing patterns that influence customer retention.

## Features
- Missing value handling
- Duplicate removal
- Outlier detection and treatment
- Exploratory Data Analysis (EDA)
- Dashboard creation using Matplotlib and Seaborn

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Outcome
Identified key factors affecting customer churn and created visual reports for business decision-making.
